# v0.2 Worker quickstart (smoke)

This page documents how to run the **v0.2 Worker Core API** scaffold on Windows without OBS.

Scope:
- Start the Worker HTTP server.
- Verify runtime directory initialization.
- Verify `GET /health`.

Non-goals:
- SQLite, queue processing, uploads, OCR, template matching.

---

## Prerequisites

- Python 3.11+ (v0.2 uses `tomllib`)

---

## Install dependencies

Create a repo-local venv (recommended):

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
```

Install Worker runtime dependencies:

```powershell
python -m pip install -r app/worker/requirements.txt
```

(Optional) Install dev/test dependencies:

```powershell
python -m pip install -r app/worker/requirements-dev.txt
```

---

## Run Worker

Run from the Worker directory so `python -m odr_worker` resolves without installing a package:

```powershell
pushd app/worker
python -m odr_worker
popd
```

The Worker binds to `127.0.0.1:8787` by default.

You can override bind host/port:

```powershell
pushd app/worker
python -m odr_worker --host 127.0.0.1 --port 8787
popd
```

---

## Verify runtime dirs

On startup, the Worker creates (idempotently):

- `user_data/config/`
- `user_data/data/`
- `user_data/logs/`

Runtime root can be overridden via `ODR_USER_DATA_DIR`.

---

## Verify GET /health

```powershell
Invoke-RestMethod http://127.0.0.1:8787/health
```

Expected:
- HTTP 200
- JSON payload containing `status`, `version`, `uptime_seconds`, `config_loaded`, `runtime_dirs_ok`, and `paths`.

---

## Run smoke tests

```powershell
python -m unittest discover -s app/worker/tests
```
