# v0.11 OBS Plugin Real Load Smoke - Acceptance Checklist

This document defines the acceptance criteria for **v0.11 - OBS Plugin Real Load Smoke** as described in:
- `docs/roadmap.md`
- #393
- #387

## Scope

v0.11 proves practical OBS plugin readiness with a real Windows OBS runtime:
- Release build of `obs-duel-recorder.dll`
- real OBS Studio x64 load smoke
- Dock visibility confirmation
- plugin startup/shutdown log confirmation
- Worker heartbeat and internal v2.3 API compatibility confirmation
- manual recording start/stop smoke
- overlay Text Source creation/reuse smoke

## Acceptance

- [ ] Windows x64, Visual Studio 2022, CMake, OBS SDK or OBS development files, Qt 6, and OBS Studio x64 environment are recorded.
- [ ] `build/plugin/Release/obs-duel-recorder.dll` is generated from the documented plugin build command.
- [ ] The generated DLL is loaded by real OBS Studio x64 without crashing OBS.
- [ ] OBS logs or ODR logs include plugin startup and shutdown evidence.
- [ ] The `OBS Duel Recorder` Dock appears.
- [ ] Worker launch or healthy Worker reuse is confirmed.
- [ ] Worker heartbeat succeeds.
- [ ] Internal Worker API version `2.3` and Worker version `2.3.0` compatibility checks pass.
- [ ] Manual recording start/stop controls are smoke-tested through OBS and Worker recording-state API linkage.
- [ ] Overlay Text Source creation or reuse is smoke-tested.
- [ ] Smoke evidence is redaction-checked before being posted to #387.

## Evidence

- Plugin build command and output artifact path.
- OBS version, Windows version, toolchain, OBS SDK/development path, and Qt path.
- OBS or ODR log excerpts for startup, shutdown, Dock, Worker heartbeat, and compatibility checks.
- Redaction-ready smoke report linked from #387.

## Non-goals

- Packaging ZIP workflow.
- Release asset automation.
- Worker/API feature expansion.
- Moving or overwriting historical/internal tags.
