# v1.3 Setup Wizard - Acceptance Checklist

This document defines the acceptance criteria for **v1.3 - Setup Wizard** as described in:

- `docs/roadmap.md`
- `docs/requirements/requirements.md`
- #322

## Scope

v1.3 creates guided setup support:

- first startup setup state
- OBS integration setup status
- OAuth setup validation
- template setup validation
- runtime path setup validation
- reset/rerun behavior

## Non-goals

- Update system implementation.
- Import/restore.
- New OCR setup flows.
- Packaging UX.

---

## Acceptance Checklist

### A. Setup State

- [x] Setup state is persisted under runtime data.
- [x] First-run, partial, complete, cancel, and reset states are represented.
- [x] Setup state survives Worker restart.
- [x] Cancel does not corrupt or delete runtime data.
- [x] Reset/rerun behavior is documented.

### B. Setup Validation

- [x] Runtime path validation checks required directories and writability.
- [x] Existing runtime data is detected and preserved.
- [x] OBS integration status surfaces Worker API/version compatibility.
- [x] OAuth validation reports missing client-secret/token files without exposing secret values.
- [x] Template validation reports missing, invalid, unreadable, or empty local templates.

### C. User Surface And Recovery

- [x] Worker API exposes current setup step and status.
- [x] Worker API exposes actionable validation diagnostics.
- [x] User-facing setup documentation covers first-run, rerun/reset, OAuth, templates, and runtime path setup.
- [x] Diagnostics do not leak OAuth secrets.
- [x] Partial setup recovery is documented.

### D. Verification

- [x] First-run detection tests pass.
- [x] Partial completion and resume tests pass.
- [x] Reset/rerun tests pass.
- [x] Setup validation tests pass.
- [x] Documentation validation passes.
