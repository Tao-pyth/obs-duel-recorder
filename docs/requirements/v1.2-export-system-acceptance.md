# v1.2 Export System - Acceptance Checklist

This document defines the acceptance criteria for **v1.2 - Export System** as described in:

- `docs/roadmap.md`
- `docs/requirements/requirements.md`
- #321

## Scope

v1.2 creates Worker-owned export support:

- ZIP export
- SQLite export
- metadata export
- screenshot export
- video linkage export
- secret and log exclusion

## Non-goals

- Import/restore implementation.
- Cloud sync.
- Update-system backup flow.
- Setup wizard.

---

## Acceptance Checklist

### A. Export Package Contract

- [x] Export ZIP structure is documented.
- [x] Manifest fields are documented and covered by tests.
- [x] Export naming is deterministic.
- [x] Failed exports do not replace existing completed archives.
- [x] Export does not mutate live runtime state.

### B. Runtime Data Export

- [x] SQLite snapshot export is produced.
- [x] Match metadata and upload queue metadata exports are produced.
- [x] Screenshot export includes existing referenced files.
- [x] Missing screenshots and videos are recorded in the manifest.
- [x] Video linkage export preserves local path, YouTube id, and YouTube URL fields.

### C. API And Exclusion Rules

- [x] Worker API can trigger an export.
- [x] Worker API returns the export output location.
- [x] Worker API can list completed exports.
- [x] OAuth tokens and client secrets are excluded.
- [x] Logs and temporary files are excluded by default.
- [x] Optional video inclusion is explicit and validated.

### D. Verification

- [x] ZIP and manifest tests pass.
- [x] SQLite and metadata export tests pass.
- [x] Screenshot and video linkage tests pass.
- [x] Secret exclusion tests pass.
- [x] Documentation validation passes.
