# Usage

Status note: This page may include planned (not-yet-released) steps. Please confirm availability in the [Roadmap](../roadmap.md).

## Automatic Recording

The system automatically:
- detects duel start
- starts recording
- detects duel end
- creates upload queue

---

## Manual Control

The Dock UI supports:
- manual start
- manual stop
- retry
- queue recovery

---

## Match Memo

Users can:
- input opponent deck
- add notes
- upload with metadata
