# インストール

← [日本語ユーザードキュメント](index.md)

このページは、導入に必要な最低限の手順をまとめます。

ステータス注記: このページには、未リリースの手順や UI 名称が含まれる可能性があります。利用可否は [ロードマップ](../../roadmap.md) で確認してください。

## 前提

- Windows
- OBS Studio

## 手順（概要）

1. リリースZIPをダウンロード
2. ZIPを展開
3. OBSプラグインのファイルを配置
4. OBSを起動
5. Worker を起動
