# YouTubeアップロード操作フロー

このページは v1.1.9 時点のDockアップロード体験を説明します。実際にYouTubeへアップロードするには、Workerが起動していること、YouTube OAuth設定が有効であること、ローカル動画ファイルが残っていること、Googleアップロード依存ライブラリを含む配布物を使用していることが必要です。

## 通常フロー

1. 録画タブで対戦を録画します。
2. 録画タブで対象動画のサムネイルと代表フレームを確認します。
3. Deck、Opponent deck、Result、メモを入力または確認します。Rank と DP は、管理タブで入力を有効にした場合だけ編集します。
4. メタデータを保存します。必須メタデータが揃うまで、紐づくキュー項目はアップロードできません。
5. `アップロードへ` を押すか、手動でアップロードタブを開きます。
6. キュー項目を選択します。アップロードタブのサムネイル、代表フレーム、対戦メタデータ、タイトル・説明文・タグのプレビュー、操作ボタンは選択中の項目に切り替わります。
7. 選択中の動画名、match ID、最終メタデータ、実行可否、ブロック理由、公開範囲を確認します。
8. 公開範囲を `private` または `unlisted` から選び、保存します。
9. `アップロード` を押します。
10. 開始前の確認で、選択中のキュー項目、動画名、タイトル、公開範囲を確認します。
11. 成功後は `YouTubeで表示する` からアップロード済み動画を開きます。

初心者向け補足: PluginはOBS Dockの画面操作とローカルWorker API呼び出しを担当します。キュー、メタデータ生成、OAuthファイル、YouTubeへのアップロード実行はWorkerの担当です。Workerが起動していない場合、Dockからアップロードはできません。

## アップロード前チェック

Dockは次の状態ではアップロードを止めます。

- キュー状態が `ready_upload` または `upload_failed` ではない
- ローカル動画ファイルが見つからない
- Deck、Opponent deck、Result のいずれかが未入力
- タイトル、説明文、タグのいずれかが空
- キュー項目にYouTube動画IDが既に保存されている
- キュー項目がアップロード済み、または破棄済み

アップロードできない場合は、選択中の対象の実行可否とブロック理由を確認してください。詳細情報はサポートやデバッグ用に残しますが、通常操作では生のパラメータを読む必要がない状態を目指します。手動確認待ちの項目は、YouTube側に途中作成された動画や重複動画がないか確認するまで再試行しないでください。

## キュー表示

アップロードタブは、作業が必要な項目を履歴より上に表示します。

- アップロード準備完了
- 失敗、または手動確認待ち
- クォータ待ち、またはアップロード中
- アップロード済み、または破棄済みの履歴

各行には、状態アイコン、状態名、キュー項目ID、match ID、作成日時、動画ファイル名を表示します。フルパスは通常表示から外し、必要なときだけ詳細確認に回します。

## 復旧操作

`再試行` はネットワーク失敗など、繰り返しても安全な失敗にだけ使います。`破棄` はローカルファイルがない場合や、今後アップロードしない項目に使います。`アップロード済みにする` は、YouTube上に動画が存在することを確認し、YouTube動画IDを入力できる場合だけ使います。Dockは保存前に `https://youtu.be/{youtube_video_id}` 形式のURLをプレビューします。

クォータ失敗は `quota_waiting` になります。クォータのリセットを待ってから再試行してください。認証失敗は手動確認待ちになります。再試行前に再認証またはトークン更新を行ってください。

## 安全な報告

アップロード問題を報告するときは、キュー項目ID、キュー状態、readiness state、next action、秘匿情報を除いたWorkerログ、ローカル動画が存在するかを共有してください。OAuthファイル、トークン、`code=...` を含む認証URL、ローカル動画、スクリーンショット、テンプレート画像、ゲーム資産は添付しないでください。
## v1.1.9 のDock操作

- アップロードタブの `メタデータを再編集する` は、キューのプルダウンで選んだ項目を録画タブへ読み込むボタンです。
- アップロード済み動画を開くボタンは `YouTubeで表示する` と表示します。認証やアップロード実行ではなく、保存済みURLを開く操作です。
- OAuth認証、OAuthトークン更新、認証ファイル保存先、キュー初期化、CSV出力は管理タブにあります。
- `ランク` と `DP` は初期状態では入力無効です。必要な場合だけ管理タブで有効にします。
- 登録状況CSVは管理タブの `CSV保存先` に出力されます。ファイル名には出力時刻が入ります。

初心者向け補足: 録画内容そのものを消す操作と、アップロード待ちキューを初期化する操作は別です。キュー初期化は動画ファイルやOAuthトークンを削除しませんが、アップロード待ちの一覧は空になります。
