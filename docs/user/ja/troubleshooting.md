# トラブルシューティング

このページは、よくある症状と切り分けの入口をまとめます。

## まず確認すること

- OBS を再起動する
- Worker を再起動する
- ログ（`user_data/logs/`）を確認する

## よくある症状

- Dock UI が表示されない
  - プラグイン導入手順を見直してください: [OBS セットアップ](obs-setup.md)

- YouTube へアップロードできない
  - OAuth 設定を見直してください: [YouTube セットアップ](youtube-setup.md)

- キューが進まない
  - 状態を確認してください: [キュー / 履歴](queue.md)
