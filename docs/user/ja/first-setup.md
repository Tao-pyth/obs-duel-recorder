# 初回セットアップ

このページは、初回起動時に最低限確認しておく項目をまとめます。

## 初回起動

- SQLite（保存データ）が存在しない場合、セットアップモードが自動的に開始する想定です。
- `user_data/` 以下に設定・ログ・データが作成されます。

## YouTube アップロード設定

YouTube へアップロードする場合は、OAuth のセットアップが必要です。

- [YouTube セットアップ](youtube-setup.md)

## オーバーレイ（テキストソース）準備

OBS のテキストソース（オーバーレイ）を事前に用意します。

- [OBS セットアップ](obs-setup.md)

## うまくいかないとき

- [トラブルシューティング](troubleshooting.md)
