# キュー / 履歴

このページは、録画後のアップロード待ち項目（キュー）と履歴の考え方をまとめます。

## キューとは

- 録画が完了した動画が、アップロード対象として並ぶ想定です。
- アップロード結果に応じて状態が変わります。

## 代表的な状態（例）

- `ready_upload`: アップロード待ち
- `uploading`: アップロード中
- `uploaded`: アップロード完了
- `upload_failed`: 失敗（リトライ可能）
- `quota_waiting`: クォータ待ち
- `need_manual_review`: 手動確認が必要
