# OBS セットアップ

このページは、OBS Studio 側の準備（プラグイン、Dock UI、テキストソース）をまとめます。

## 役割分担（重要）

- OBS プラグイン: OBS 統合、Dock UI、オーバーレイ更新、Worker 管理
- Python Worker: キュー処理、DB、アップロードなどの重い処理

## プラグインの導入（概要）

1. リリース ZIP を展開します。
2. OBS のプラグイン配置場所へファイルをコピーします。
3. OBS を再起動します。

## Dock UI（概要）

- OBS のドックとして UI が表示される想定です。
- まずは Worker の起動・状態確認ができることを目標にします。

## テキストソース / オーバーレイ（概要）

- 事前に必要なテキストソースを作成します。
- どのソース名を使うかは、今後のドキュメント整備で確定します。
