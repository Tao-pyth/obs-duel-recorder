# 自動録画セットアップ

-> [日本語ユーザードキュメント](index.md)

ステータス注記: このページは v1.1.4 のガイド付きセットアップ目標を説明します。自動録画は Plugin ビルドと実 OBS smoke 検証が完了するまで、リリース済み機能として扱わないでください。

## 何をする機能か

自動録画は、ローカルの開始/終了テンプレートを使って対戦の開始と終了を判定します。OBS Plugin はセットアップ時に現在の OBS Program 画像を取得します。Worker はテンプレート保存、画像一致、録画状態判断を担当します。

このプロジェクトはゲーム資産やテンプレート画像を配布しません。取得したテンプレートは `user_data/` 配下のユーザー実行時データであり、git、公開ドキュメント、リリースパッケージに含めないでください。

## ガイド付きセットアップ手順

1. OBS Studio で「対戦開始」と判断したい画面を表示します。
2. `OBS Duel Recorder` Dock を開きます。
3. `管理` タブへ移動します。
4. 自動録画セットアップを開きます。
5. `開始画面として取得` を押します。
6. 「対戦終了」と判断したい画面を表示します。
7. `終了画面として取得` を押します。
8. 対象画面を表示したまま `現在画面でテスト` を押します。
9. 検出が緩すぎる、または厳しすぎる場合だけ、しきい値と確認回数を調整します。
10. 開始/終了テストの結果が理解できる状態になってから、`管理` タブの `自動検出` を有効にします。

## 操作項目

| 操作 | 目的 |
|---|---|
| `開始画面として取得` | 現在の OBS Program 画像を開始テンプレートとして保存します。 |
| `終了画面として取得` | 現在の OBS Program 画像を終了テンプレートとして保存します。 |
| `現在画面でテスト` | 現在画像を開始/終了テンプレートに照合します。録画状態は変更しません。 |
| `しきい値` | 一致とみなす最低スコアです。高いほど厳しくなります。 |
| `確認回数` | 状態遷移前に必要な連続一致回数です。高いほど誤検出は減りますが反応は遅くなります。 |
| `自動検出` | OBS から Worker へ周期的にフレームを送る機能を有効にします。テンプレート設定中は無効のままにしてください。 |
| `送信間隔` | 自動フレーム送信の最小間隔です。大きくすると負荷は下がりますが反応は遅くなります。 |

## トラブルシューティング

取得できない:
- OBS が起動しており、Worker が正常であることを確認します。
- OBS が設定済み出力先へスクリーンショットを書けることを確認します。
- 取得したい scene/source に切り替えてから再試行します。

テンプレートがない:
- 開始画面と終了画面を再取得します。
- `user_data/templates/` と `user_data/config/templates.toml` が作成されているか確認します。

一致しない:
- 取得時と同じ画面状態でテストします。
- しきい値を少しずつ下げます。
- scene、解像度、crop が取得時と変わっていないか確認します。

誤検出する:
- しきい値を少しずつ上げます。
- 確認回数を増やします。
- より特徴的な画面状態を取得し直します。

負荷が高い:
- `送信間隔` を大きくします。
- OBS または Worker が不安定になる場合は `自動検出` を無効にします。
- v1.1.4 のフレーム送信は一時スクリーンショットを読み取り後に削除しますが、実 OBS smoke でファイルが残らないことを確認してください。

Worker に接続できない:
- まず `管理` タブの診断を確認します。
- Dock が Worker unhealthy / stopped を表示する場合は、設定から Worker を再起動します。

## 実 OBS smoke チェックリスト

- [ ] Plugin が OBS x64 に読み込まれる。
- [ ] Worker が起動し、health が running になる。
- [ ] `開始画面として取得` が OBS インストール先ではなく runtime 配下にテンプレートを作成する。
- [ ] `終了画面として取得` が OBS インストール先ではなく runtime 配下にテンプレートを作成する。
- [ ] `現在画面でテスト` が録画開始/停止を行わずに開始/終了の照合診断を返す。
- [ ] `自動検出` を有効化でき、Worker が正常な時だけ bounded periodic frame を送信する。
- [ ] 自動フレーム送信の一時スクリーンショットファイルが残らない。
- [ ] 自動検出を有効にしても手動の録画開始/停止が使える。
- [ ] ログに画像バイト列、テンプレート内容、OAuth secret、ゲーム資産が出ない。
