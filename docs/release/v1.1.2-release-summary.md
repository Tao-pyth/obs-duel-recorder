# v1.1.2 Release Summary

Tracking issue: #457

## Status

Released on 2026-05-27.

## Scope

`v1.1.2` groups the post-`v1.1.1` recovery update work for:

- automatic error reporting operation documentation (#453)
- release package validation that rejects fixture or non-PE Plugin/Worker
  executables (#454)
- compact OBS Dock navigation for Setup, Settings, Help, Automatic Setup, and
  Diagnostics (#455)
- Japanese/English language selection in Settings with Help recovery text (#456)

## Implementation Notes

- `scripts/build_release_package.ps1` validates both
  `app/plugin/obs-duel-recorder.dll` and
  `app/worker/odr-worker/odr-worker.exe` as Windows PE files before packaging.
- `scripts/validate_release_package.ps1` validates the packaged Plugin DLL and
  Worker EXE as PE files inside the ZIP.
- The CI package-layout fixture now uses generated PE files instead of text
  placeholders.
- The OBS Dock is organized with tab navigation so secondary surfaces are not
  all visible at once.
- Settings persists `ui_language` with `en` and `ja` options and immediately
  refreshes tab labels, action buttons, notes, and diagnostics labels.
- Help includes a language-change note in the opposite language from the active
  UI language.
- Automatic error reporting is documented as a relay-owned GitHub Issues
  operation; GitHub tokens must not be distributed in app packages.
