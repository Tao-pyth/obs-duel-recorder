# v0.11 Release Readiness Checklist

This checklist helps contributors prepare **v0.11 - OBS Plugin Real Load Smoke** on the practical readiness track.

Scope:
- Evidence and verification steps for real OBS plugin build/load smoke.
- No packaging automation work is performed by this checklist.

Quick links:
- Version tracking issue: #393
- Smoke evidence gate: #387
- Acceptance checklist: `docs/requirements/v0.11-obs-plugin-real-load-smoke-acceptance.md`
- Smoke procedure: `docs/architecture/v0.11-obs-plugin-smoke.md`

Non-goals:
- Completing v0.12 Release Packaging Automation.
- Declaring practical v1.0 readiness before OBS smoke and packaging gates pass.

---

## A. Environment Readiness

- [ ] Windows x64 environment is recorded.
- [ ] `scripts/check_v0_11_obs_smoke_env.ps1` output is recorded.
- [ ] Visual Studio 2022 C++ build tools are available.
- [ ] CMake is available.
- [ ] OBS Studio x64 is installed and version is recorded.
- [ ] OBS SDK or development files are available to CMake.
- [ ] Qt 6 Widgets development package is available to CMake.

## B. Build Readiness

- [ ] Plugin configure command is recorded.
- [ ] Plugin Release build command is recorded.
- [ ] `build/plugin/Release/obs-duel-recorder.dll` exists.
- [ ] Build output does not include secrets, runtime data, logs, screenshots, videos, DBs, OAuth tokens, or game assets.

## C. OBS Load Smoke

- [ ] Plugin DLL is loaded into real OBS Studio x64.
- [ ] OBS does not crash or immediately unload the plugin.
- [ ] `OBS Duel Recorder plugin startup` evidence is recorded.
- [ ] `OBS Duel Recorder plugin shutdown` evidence is recorded.
- [ ] `OBS Duel Recorder` Dock appears.

## D. Worker And Feature Smoke

- [ ] Worker launch or healthy Worker reuse is confirmed.
- [ ] Worker heartbeat succeeds.
- [ ] Internal Worker API version `2.3` compatibility check passes.
- [ ] Internal Worker version `2.3.0` compatibility check passes.
- [ ] Manual recording start/stop controls are smoke-tested.
- [ ] Overlay Text Source creation or reuse is smoke-tested.

## E. Evidence And Handoff

- [ ] Smoke report is redaction-checked.
- [ ] Smoke report is posted to #387.
- [ ] #393 reflects final child issue state.
- [ ] v0.12 Release Packaging Automation remains the next practical readiness target.
