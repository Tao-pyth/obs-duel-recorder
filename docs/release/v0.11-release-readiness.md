# v0.11 Release Readiness Checklist

This checklist helps contributors prepare **v0.11 - OBS Plugin Real Load Smoke** on the practical readiness track.

Scope:
- Evidence and verification steps for real OBS plugin build/load smoke.
- No packaging automation work is performed by this checklist.

Quick links:
- Version tracking issue: #393
- Smoke evidence gate: #387
- Acceptance checklist: `docs/requirements/v0.11-obs-plugin-real-load-smoke-acceptance.md`
- Smoke procedure: `docs/architecture/v0.11-obs-plugin-smoke.md`

Non-goals:
- Completing v0.12 Release Packaging Automation.
- Declaring practical v1.0 readiness before OBS smoke and packaging gates pass.

---

## A. Environment Readiness

- [x] Windows x64 environment is recorded.
- [x] `scripts/check_v0_11_obs_smoke_env.ps1` output is recorded.
- [x] Visual Studio 2022 C++ build tools are available.
- [x] CMake is available.
- [x] OBS Studio x64 is installed and version is recorded.
- [x] OBS SDK or development files are available to CMake.
- [x] Qt 6 Widgets development package is available to CMake.

## B. Build Readiness

- [x] Plugin configure command is recorded.
- [x] Plugin Release build command is recorded.
- [x] `build/plugin/Release/obs-duel-recorder.dll` exists.
- [x] Build output does not include secrets, runtime data, logs, screenshots, videos, DBs, OAuth tokens, or game assets.

## C. OBS Load Smoke

- [x] Plugin DLL is loaded into real OBS Studio x64.
- [x] OBS does not crash or immediately unload the plugin.
- [x] `OBS Duel Recorder plugin startup` evidence is recorded.
- [x] `OBS Duel Recorder plugin shutdown` evidence is recorded.
- [x] `OBS Duel Recorder` Dock appears.

## D. Worker And Feature Smoke

- [x] Worker launch or healthy Worker reuse is confirmed.
- [x] Worker heartbeat succeeds.
- [x] Internal Worker API version `2.3` compatibility check passes.
- [x] Internal Worker version `2.3.0` compatibility check passes.
- [x] Manual recording start/stop controls are smoke-tested.
- [x] Overlay Text Source creation or reuse is smoke-tested.

## E. Evidence And Handoff

- [x] Smoke report is redaction-checked.
- [x] Smoke report is posted to #387.
- [x] #393 reflects final child issue state.
- [x] v0.12 Release Packaging Automation remains the next practical readiness target.
