## Limitations

- This was an isolated OBS smoke, not the final real
  `C:\Program Files\obs-studio` installation.
- The non-elevated real OBS install attempt failed with `Access denied` while
  copying `obs-duel-recorder.dll` into Program Files.
- OBS did not exit within 15 seconds through automated `CloseMainWindow()` in
  this smoke run, so the process and its spawned Worker were force-stopped.
  Normal user-initiated OBS shutdown cleanup still needs manual real OBS
  validation before release closure.
- Dock visual layout was not screenshot-verified in this automated run.
