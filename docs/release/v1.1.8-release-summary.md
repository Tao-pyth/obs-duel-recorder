# v1.1.8 Release Summary

## Purpose

v1.1.8 is a real OBS Dock usability correction release for #595.

The release focuses on narrow Dock readability: action buttons must remain legible, duplicate preview/settings surfaces should not compete with the main workflow, representative frame selectors must not look like previous/next navigation, and upload text templates need their own visible editing space.

## Included Work

- Reworked Record tab metadata actions into a two-column button grid.
- Removed the Record tab upload text preview button because the same review belongs with upload/template work.
- Removed previous/next arrow icons from representative-frame selectors.
- Reworked Upload tab action and OAuth controls into two-column button grids with shorter labels and retained tooltips.
- Added a dedicated Template tab for upload title, description, tag editing, and preview.
- Removed the duplicate Open Settings button from Manage while keeping inline settings and Save Settings.
- Updated user and architecture documentation for the Record / Upload / Template / Manage Dock structure.

## Validation

- Worker full unit test discovery passed.
- Markdown link validation passed.
- C++ Plugin build passed with MSVC Build Tools and the existing `NMake Makefiles` build directory.
