## Implementation Evidence

Record concrete evidence here as work completes.

- `POST /setup/templates/capture` stores captured template content under
  `user_data/templates/`, updates `user_data/config/templates.toml`, and reloads
  detection runtime.
- Captured template registration is covered by Worker setup wizard tests.
- `POST /detection/test` and `POST /detection/frame` accept captured PNG frame
  bytes through `frame_base64` and match them against user runtime PNG
  templates without adding committed game assets.
- Automatic setup Dock actions can capture the current OBS Program screenshot
  for start/end template registration and current-screen detection tests. This
  path is reused by the setting-gated v1.1.4 automatic detection feed.
- `GET /matches/{match_id}/video-preview` returns a representative PNG frame
  for the metadata editing target when the linked video exists and local ffmpeg
  is available. The Dock shows frames `1`, `2`, and `3` without switching away
  from the current metadata target.
- The Plugin now has a setting-gated periodic detection feed. When
  `automatic_detection_enabled` is true, Worker state is `running`, and manual
  recording is not active, the Dock sends bounded `frame_base64` PNG payloads
  to `/detection/frame` at `automatic_detection_interval_ms`.
- Major Dock action buttons use Qt standard icon roles with localized tooltips.
  MDI candidates and Pictogrammers license handling are documented in
  `docs/architecture/dock-icons.md`.
- `/upload/status` exposes a stable `readiness` contract plus compact
  `readiness_state` and `readiness_next_action` fields for Plugin UI display.
  The Dock YouTube link row consumes those compact fields without reading
  secret files directly.
- The Upload tab now exposes operator actions for YouTube authorization URL
  launch, token refresh, and OAuth setup help. These buttons call the Worker
  OAuth API and never read OAuth secret files directly.
- `docs/user/youtube-oauth.md` and `docs/user/ja/youtube-oauth.md` document the
  normal-user OAuth setup, token refresh, readiness states, and safe support
  reporting rules for #490.
- Quota classification covers `quotaExceeded`, `dailyLimitExceeded`,
  `userRateLimitExceeded`, and HTTP `429`; docs explain that `next_attempt_at`
  is not invented when reset time is unknown.
- Manual-review recovery requires a plain YouTube video ID for `mark_uploaded`
  and rejects obvious URL/pasted-text mistakes.
- Upload metadata preview and real upload metadata include `privacy_status`;
  the Dock preview dialog exposes the privacy value before upload.
- Guided automatic recording setup is documented for users in English and
  Japanese, including capture/test controls, local-template safety rules,
  troubleshooting, and the real OBS smoke checklist.
- OBS Program Files installation requires an elevated shell. A normal-permission
  install attempt on this workstation failed at Plugin DLL copy with
  `Access denied`, so real OBS runtime smoke remains pending administrator
  approval.
