# v1.1.1 Verification Matrix

This matrix defines the required verification evidence before #440 / `v1.1.1` can be considered complete.

The matrix distinguishes:
- local environment blocker: this workstation cannot run the check because a prerequisite is missing,
- release blocker: the check can run and fails, or required evidence is absent for the release decision.

## Summary

| Area | Required before #440 closes | Evidence destination |
|---|---|---|
| Worker tests | Yes | #450 and final readiness record |
| Plugin build or OBS smoke | Yes | #450 and #451 |
| Release package validation | Yes when packaging is built | #451 and release history |
| Documentation validation | Yes | #450 and readiness record |
| UI/manual smoke | Yes for Dock, Settings themes, Help, and automatic recording setup | #450 |
| Release publication records | Yes | #451 and release history |

## Plugin Build And OBS Smoke Matrix

Prerequisites:
- Windows x64
- OBS Studio latest stable x64
- Visual Studio 2022 with C++ desktop workload
- CMake 3.24+
- OBS CMake package files and development headers/libraries in `CMAKE_PREFIX_PATH`
- Qt 6 Widgets development package in `CMAKE_PREFIX_PATH`

Build command:

```powershell
cmake -S app/plugin -B build/plugin -G "Visual Studio 17 2022" -A x64 -DCMAKE_PREFIX_PATH="<obs-prefix>;<qt-prefix>"
cmake --build build/plugin --config Release
```

Expected artifact:

```text
build/plugin/Release/obs-duel-recorder.dll
```

| Gate | Manual or command evidence | Failure classification |
|---|---|---|
| P1 Plugin build | Release DLL exists at `build/plugin/Release/obs-duel-recorder.dll` | Release blocker if prerequisites are available; local environment blocker if CMake/OBS/Qt/VS prerequisites are absent |
| P2 OBS load smoke | DLL loads in OBS Studio x64; OBS log shows plugin startup without crash | Release blocker if a built DLL and OBS runtime are available |
| P3 Dock smoke | Dock opens, Worker status updates, Start/Stop state follows Worker/OBS state | Release blocker |
| P4 Dock UI smoke | redesigned Dock is readable, colorful, non-debug-dominant, and diagnostics remain accessible | Release blocker |
| P5 Settings theme smoke | each selectable theme persists, applies to the Dock, and does not obstruct setup/record/upload controls | Release blocker |
| P6 Help smoke | Help opens from the Dock and covers setup, manual recording, automatic recording, metadata review, upload review, and diagnostics | Release blocker |
| P7 OBS source smoke | documented OBS Text Source names are created or reused as documented; missing/duplicate/unsupported sources produce actionable diagnostics | Release blocker |

Current local prerequisite check for this workstation:
- `cmake --version`: local environment blocker, `cmake` is not on `PATH`.
- `where.exe cmake`: local environment blocker, no executable found.
- `where.exe obs64.exe`: local environment blocker, OBS executable is not on `PATH`.

These local blockers do not prove product failure. They must be resolved on a build/smoke workstation or recorded in #450 before release completion.

## Release Package Matrix

The package builder expects a built Plugin DLL and a bundled Worker executable.

```powershell
python -m pip install "./app/worker[bundle]"
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\build_worker_exe.ps1 -OutputDir build\worker -Clean
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\build_release_package.ps1 -Version v1.1.1 -PluginDllPath build\plugin\Release\obs-duel-recorder.dll -WorkerBundlePath build\worker\odr-worker -OutputDir build\release -Clean
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\validate_release_package.ps1 -PackageZip build\release\obs-duel-recorder-v1.1.1.zip -ChecksumFile build\release\SHA256SUMS.txt -ExpectedVersion v1.1.1
```

| Gate | Required evidence | Failure classification |
|---|---|---|
| R1 Worker executable bundle | `build/worker/odr-worker/odr-worker.exe` exists and package build consumes it | Release blocker |
| R2 ZIP layout | ZIP contains Plugin DLL, Worker bundle, install/update scripts, minimal docs, manifest, README, and LICENSE | Release blocker |
| R3 Exclusions | ZIP excludes `user_data`, logs, SQLite DBs, screenshots, videos, OAuth files, local templates, and game assets | Release blocker |
| R4 SHA256 | `SHA256SUMS.txt` contains the ZIP checksum | Release blocker |
| R5 Install/update check | packaged `install.bat`, `verify-install.bat`, and `update.bat` are exercised on a disposable OBS root or documented smoke machine | Release blocker unless explicitly deferred by maintainer approval |
